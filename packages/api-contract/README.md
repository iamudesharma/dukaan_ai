# DukaanAI API contract

`openapi.json` is the checked-in OpenAPI 3 contract generated by Django REST
Framework's drf-spectacular schema. It is the canonical low-level wire contract;
the web and Flutter repositories add client-specific camelCase mapping,
minor-unit helpers, role-aware behavior, token refresh, and idempotency.

Regenerate from the repository root (Node 22, uv 0.9.17, JDK 21, and Dart 3.8+
are required):

```sh
npm run schema:generate
npm run clients:generate
```

CI runs `npm run schema:check` and `npm run clients:check` in the web/API-contract
job, plus `npm run clients:dart:check` and `dart analyze` in the Flutter job, so
schema or generated-client drift fails the required gate. Generation never needs
a running API, database credentials, production secrets, OCR models, or provider
accounts.

Outputs:

- `openapi.json`: canonical OpenAPI 3 snapshot.
- `src/types.ts`: generated TypeScript path/component types.
- `src/client.ts`: small `openapi-fetch` client factory.
- `dart/`: generated Dart/Dio models, serializers, auth helpers, and API classes.

The application repositories intentionally remain hand-written: they add token
refresh, camelCase compatibility, role-aware privacy, offline drafts, and
idempotency behavior that a generic generator cannot infer.
